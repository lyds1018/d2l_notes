## 一、处理流程
### 1. 训练数据

```
原始图像
→ Resize / RandomResizedCrop
→ 图像数据增广
→ ToTensor
→ RandomErasing
→ Normalize
```

- RandomResizedCrop: 随机裁剪 + Resize

### 2. 测试数据

```
原始图像
→ Resize
→ CenterCrop
→ ToTensor
→ Normalize
```

- CenterCrop: 中心裁剪

---

## 二、标准格式

```python
import torchvision.transforms as T

train_transform = T.Compose([
    T.RandomResizedCrop(224),
    T.RandomHorizontalFlip(),
    T.ToTensor(),
    T.RandomErasing(p=0.5),
    T.Normalize(mean, std),
])
```
