## 一、几何类增广 

| 方法            | torchvision.T          |
| ------------- | ---------------------- |
| 居中裁剪          | `CenterCrop`           |
| 随机裁剪 + Resize | `RandomResizedCrop`    |
| 水平翻转          | `RandomHorizontalFlip` |
| 垂直翻转          | `RandomVerticalFlip`   |
| 随机旋转          | `RandomRotation`       |
| 平移 / 缩放 / 仿射  | `RandomAffine`         |

## 四、自动化增广

| 方法          | torchvision.T |
| ----------- | ------------- |
| RandAugment | `RandAugment` |
| AutoAugment | `AutoAugment` |

```python
import torchvision.transforms as T

T.AutoAugment(
    policy=T.AutoAugmentPolicy.IMAGENET
)

T.RandAugment(
    num_ops=2,     # 每张图用几个操作
    magnitude=9    # 操作强度
)
```

- 常见 policy: IMAGENET, CIFAR10, SVHN

## 五、样本拼接 CutMix

**不在 transform 里，用在训练 batch 中**

```python
from torchvision.transforms.v2 import CutMix

cutmix = CutMix(num_classes=1000)  # 分类数

for images, labels in train_loader:
    images, labels = cutmix(images, labels)

    outputs = model(images)
    loss = criterion(outputs, labels)

    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
```

- 拼接后，标签按面积比例混合
